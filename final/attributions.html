This student project aims to keep its sources and contributions clear. Here is what went into Kampala Food Explorer.

01

Writing & food notes

Original concise descriptions prepared for this coursework project by Dira Luke. They are introductory summaries, not definitive culinary histories or dietary advice.

02

Visual design & code

Page layouts, project code, and original decorative illustrations were created for this site. No external code library is used.

03

Data & browser storage

The dish catalogue is a local JSON file included with this site. Saved dishes are stored in the visitor’s browser only; recommendations are shown from the page URL and are not sent to a server.

04
